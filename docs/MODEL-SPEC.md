# Model Spec — 敷地・建物・地表・配置の現行仕様

最終更新: 2026-08-07

本書は3Dモデルと配置の「現在どうなっているか」を記録する。機械可読な座標・寸法の正本は`data/fixed-site-data.js`と各catalogであり、本書には座標系、代表値、形状の意味、設計判断を記録する。変更ルールは[`DATA-GOVERNANCE.md`](DATA-GOVERNANCE.md)を参照する。

## 1. 座標系と敷地

- ワールド座標は`x`が東西、`z`が南北、`y`が高さ。建物ローカル座標では`x`が西から東、`z`が北から南、`y`がGLから上方向。
- 統合敷地外周は14点、約971.02㎡。
- 宅地境界は11点。申請宅地面積は319.67㎡、座標から求めた幾何面積は約320.95㎡。
- 畑側は旧敷地を宅地南端の段状境界で分割した7点ポリゴンで、幾何面積は約650.08㎡。
- 緯度・経度の基準値は北緯33.32、東経130.94。
- 北側道路と転回エリアは`js/site-model.js`で両ワークスペース共通表示とし、旧道路形状は使用しない。
- 宅地・畑の境界、固定園路、輪作区画、樹木、施設の正確な頂点列は`data/fixed-site-data.js`を参照する。

## 3. 建物

出典: 有限会社天領住宅 二級建築士事務所「渡辺拳竜様邸新築工事_Ver5」全4葉、敷地・建物解析済み `ishii_site_digital_twin_v5.html`

建物部分は、図面を基にした初期実装後の目視確認と手動修正を反映している。図面の初期解釈と現在の表示が異なる箇所では、`data/fixed-site-data.js`と`js/building-model.js`の現行実装を正とする。

### 3.1 座標系と建物外形

- 建物ローカル座標は、`x` が西から東、`z` が北から南、`y` がGLから上方向。
- 建物ローカル原点（北西基準）はワールド座標 `{ x: -7.346, z: -13.089 }`。
- 建物中心は `{ cx: 2.209, cz: -9.2215 }`。
- 固定データ上の最大外接寸法は、幅19.110m、奥行7.735m。
- `wallH: 6.300m` は建物データの互換用上限値であり、平屋部の壁を一律6.300mで生成する指定ではない。
- REAL表示では、下記4区画の段状平面を個別に生成する。旧来の19.11m × 7.28mの単純な直方体には戻さない。

### 3.2 平面形状

北面はA1からA3へ0.455mずつ後退し、南面はA1〜A3がローカル `z=6.370m` で揃う。A4だけが南へ1.365m張り出す。

|---|---:|---:|---:|---:|---:|---:|---|
| A1 | 0.000–9.100 | 9.100 | 0.910 | 5.460 | 6.370 | 49.686 | 民泊棟 |
| A2 | 9.100–12.740 | 3.640 | 0.455 | 5.915 | 6.370 | 21.531 | デッキ・自室玄関・北玄関 |
| A3 | 12.740–16.380 | 3.640 | 0.000 | 6.370 | 6.370 | 23.187 | 自宅LDK・階段 |
| A4 | 16.380–19.110 | 2.730 | 0.000 | 7.735 | 7.735 | 21.117 | 水回り・南土間 |

- 1階床面積のモデル合計は115.521㎡（図面表記115.51㎡、丸め差0.011㎡）。
- 2階はA3・A4上部の6.370m × 6.370m、ローカル `x=12.740–19.110m`、`z=0–6.370m` に配置する。
- 2階床面積は40.577㎡（図面表記40.57㎡）。

### 3.3 高さ

すべてGL基準。

| 項目 | 値 (m) | 現行モデルでの扱い |
|---|---:|---|
| 1FL | 0.500 | 基礎天端・外壁下端 |
| 2FL | 3.232 | 2階外壁下端 |
| 平屋屋根の基準低位 | 3.400 | ローカル `z=-0.500m` における屋根面の基準値 |
| 平屋屋根の南端高位 | 4.567 | ローカル `z=7.280m` の共通南端 |
| 2階軒高 | 6.300 | 2階外壁上端 |
| 2階棟高 | 7.423 | 切妻屋根の棟 |

平屋部の北端は段状平面に従うため、A1とA2で屋根端および壁上端の高さがわずかに異なる。`eaveLow` は全北軒の実座標を意味せず、片流れ面を決める基準高として使用する。

### 3.4 屋根

#### 3.4.1 平屋部の片流れ屋根

- 対象はA1・A2（ローカル `x=0–12.740m`）。A3・A4の2階部分へは重ねない。
- 勾配は1.5寸（`0.15`）。
- **北側が低く、畑側である南側へ向かって高くなる。** 初版文書にあった「北が高く南が低い」は、目視確認後の修正前の記述であり現行仕様ではない。
- A1・A2をそれぞれの段状北面から生成し、南端は袖壁を含むローカル `z=7.280m` に揃える。
- 北・南の軒出は0.500m、東西の破風側の出は0.220m、屋根厚は0.180m。
- 屋根端には破風・鼻隠し相当の縁材を付ける。
- 雨樋はA1・A2の北側低位軒先に配置する。南側に垂直に伸びていた不要な竪樋2本は、目視修正により削除済み。

#### 3.4.2 2階切妻屋根

- 対象はローカル `x=12.740–19.110m`、`z=0–6.370m`。
- 3寸勾配（`0.30`）で、棟は東西方向。
- 軒高6.300m、棟高7.423mを維持する。
- 北・南の軒出は0.558m、東西の破風側の出は0.220m、屋根厚は0.180m。
- 東西の三角形の妻壁で屋根下を塞ぎ、壁面から飛び出さない向きに配置する。
- 北側・南側の両軒先に雨樋を配置する。

#### 3.4.3 南東部の下屋

- A4南側の張り出し上部に、2階本体とは別の片流れ下屋を設ける。
- ローカル範囲は概ね `x=16.160–19.330m`、`z=6.370–8.235m`。
- 屋根上面は北側3.780m、南側3.500mで、南へ向かって低くなる。
- 屋根厚は0.160m。東側の屋根下は専用の壁形状で塞ぎ、壁と屋根の間に穴を残さない。
- この下屋は、手動修正で真下のA4建物位置へ合わせた現行位置を正とする。

#### 3.4.4 庇

- A4東面のルーバードア上に小庇を設ける。
- A3・A4北面には、北側アプローチ用の連続庇と2本の支持柱を設ける。
- 自室玄関には独立した玄関庇、ポーチ、柱を設ける。

### 3.5 外壁・基礎・付加壁

- A1・A2は1階建て、A3・A4は2階建てとして壁面を分割生成する。
- 基礎はGLから1FLまで立ち上げ、外壁との境界に水切りを付ける。
- REAL表示では各区画の下に薄い接地影を置く。
- 北面のローカル `x=0–11.400m` は杉サイディング。現在の既定色は濃色で、APPEARANCEから変更できる。
- 自室玄関袖壁は杉仕上げ、民泊玄関袖壁は通常外壁仕上げ。
- 南面にはローカル `x=-0.180–0.000m` と `x=12.560–12.740m` の2枚の目隠し壁を設ける。
- A4南張り出し部は、2階床高までの外壁と南東下屋の組み合わせで表現する。
- 外壁角には見切り材、軒下には軒裏材を配置する。

### 3.6 開口部

固定データには計18件の開口部を登録している。

| 面 | 件数 | 配置の扱い |
|---|---:|---|
| 北 | 4 | A1〜A4の段状北面に配置 |
| 南 | 8 | A1〜A3の共通南面およびA4南張り出し面に配置 |
| 東 | 4 | A4東端面に配置 |
| 西 | 2 | A1西端面に配置 |

- 位置・幅・高さは `data/fixed-site-data.js` の `building.openings` を正とする。
- 2階開口は2階区画の壁面に追従し、壁から不自然に飛び出さない向きで配置する。
- REAL表示では暗い室内面、ガラス、サッシ、水切りを重ねて奥行きを表現する。
- 現行モデルはCSGで壁をくり抜かず、壁面上に開口部形状を重ねる軽量表現である。
- 自室玄関、民泊玄関、A4東面ルーバードアは、それぞれの固定開口データに従う。

### 3.7 REAL / PLANの差

REAL表示は、段状壁、基礎、水切り、杉サイディング、妻壁、下屋、庇、袖壁、目隠し壁、雨樋、開口部の詳細を表示する。

PLAN表示は、寸法と配置の可読性を優先した簡略モデルである。4区画の1階ボリューム、2階ボリューム、切妻屋根、片流れ屋根、窓・玄関位置は維持するが、下屋・庇・樋などの細部は省略できる。REALとPLANで建物中心や固定平面寸法を変えない。

### 3.8 面積

| 項目 | 面積 (㎡) |
|---|---:|
| 建築面積 | 139.08 |
| 1階床面積 | 115.51 |
| 2階床面積 | 40.57 |
| 延べ床面積 | 156.08 |
| 屋根付き・床面積外 | 23.57 |
| 申請宅地面積 | 319.67 |

建築面積と1階床面積の差23.57㎡は、屋根はあるが床面積に算入されない空間を含む。モデルでは平屋部南側の軒下空間などとして表現するが、個別範囲の確定には施工図の確認が必要である。

### 3.9 マテリアルと表示上の方針

- REAL用マテリアルは `js/building-materials.js` で共有し、外壁、基礎、屋根、杉、木部、金属、ガラス、樋、室内暗部を使い分ける。
- 256px以下のプロシージャルテクスチャを使用し、色テクスチャはsRGB、高さ情報はLinearとして扱う。
- 杉サイディングは縦方向の質感を持つが、強い粒状ノイズは使用しない。
- PLANは単色系の簡略マテリアルを使用する。
- REAL / PLAN切替時は建物グループを再構築し、共有マテリアルと共有テクスチャを破棄しない。

### 3.10 現時点の簡略化・要確認事項

1. 内部間取り、構造材、断熱層、屋根納まりはモデル化していない。
2. 窓・ドアは壁を実際に切り欠く形状ではなく、表示負荷を抑えた重ね合わせ表現である。
3. 外部設備は確定情報のないものを常設せず、現行モデルでは主要な建物外形と外装を優先する。
4. 外壁、杉、屋根の最終色は施工サンプル確定後に変更される可能性がある。
5. 図面からの初期読取りより、アプリ上で確認済みの屋根方向・妻壁方向・下屋位置を優先している。

## 4. 畑・地表・植栽・施設

### 4.1 固定配置

- 固定園路は4件。現在の短い東端園路は宅地へ侵入しないよう畑境界内へ切り詰めている。
- 輪作区画はA〜Dの4区画。PLAN A/Bや地表編集の変更は差分として保存し、固定値へ書き戻さない。
- 固定樹木は10本、9樹種。ウメ、イチジク、ブルーベリー2本、ユズ、キンカン、甘夏、カキ、ジューンベリー、ヤマボウシで構成する。
- 作業ヤード、倉庫、資材箱、浅井戸・ポンプ・洗い場、ゲスト収穫ガーデン、ハーブ帯、芝・クローバー広場、パーゴラを初期配置する。
- 倉庫は畑側へ収め、入口が畑中央を向くようY軸まわりに-90度回転している。ユズと資材箱はこの配置と干渉しない現行位置を正とする。

### 4.2 緑肥・グランドカバー

畑の未利用域を管理可能な地表として扱うため、独立した描画レイヤーを増やさず、既存のground-featureシステムへ統合している。正確なポリゴン頂点は`js/ground-feature-catalog.js`の`GREEN_MANURE_ZONES`を正本とする。

| ゾーン | 用途 | 種別 | 表示上の役割 |
|---|---|---|---|
| G1 | 西の花畑 | クリムソンクローバー | PLANでは赤系で識別 |
| G2 | 南の緑肥ローテーション | ソルゴー／ヘアリーベッチ | PLANでは黄土系のパターンで識別 |
| G3 | 東の果樹草生 | クローバー | 果樹下の草生管理 |
| G4 | 中央クローバー | クローバー | 中央未利用域の被覆 |
| G5 | 北縁の緩衝帯 | クローバー | 道路・境界側の被覆 |
| G6 | 動線南の帯、2区画 | クローバー | 園路沿いの被覆 |
| G7 | こぼれ地、4区画 | クローバー | 果樹間や通路際の細部を被覆 |

- 全11ポリゴンは`lawn`レイヤーに属し、地表編集、PLAN A/B、undo / redo、面積集計の対象となる。
- 地表高さは`y=0.036m`。輪作区画の`y=0.037m`よりわずかに低くし、重なった場合は輪作を上に表示する。
- REALは既存クローバー系マテリアルを共有し、PLANは種別ごとの色とパターンを使って用途を識別する。
- 区画形状は現地の日照、水はけ、傾斜を反映した確定施工範囲ではなく、GROUND EDITで調整する設計初期値である。

### 4.3 編集データ

- 既存植物・設備・地表の移動や形状変更は、PLAN A/B別の`overrides`として保存する。
- 追加要素は`additions`として保存し、固定データとは区別する。
- REALとPLANは同じ解決済み座標を使用する。
- 初期差分が空の場合は、本書と固定データに記載した初期景観を再現する。

## 5. 表示設定と非幾何データ

- 季節、成長年数、花・実、描画品質、表示レイヤー、ラベル、カメラ、REAL / PLANは実行時状態であり、固定座標ではない。
- 外壁・杉・屋根の色変更は共有マテリアルへ適用し、建物形状や固定データを変更しない。
- ワークスペースは`field`と`exterior`の2種類。共通道路は両方に表示し、その他のrootグループは`js/workspaces.js`の定義に従う。
- 表示設定の保存・読込は設計差分と区別し、古い設定データを読み込んでも固定データを上書きしない。
